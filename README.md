# Request Admin System

PHP 7.2 destekli İdari İşler Talep Yönetim Sistemi

## Özellikler

- Firma kayıt ve onay sistemi
- 3 farklı kullanıcı rolü (Admin, İdari İşler Yetkilisi, Çalışan)
- Lokasyon bazlı yetkilendirme
- Talep yönetimi ve takip sistemi
- E-posta bildirimleri
- Dashboard ve raporlama
- Güvenlik ve log sistemi

## Kurulum

1. PHP 7.2+ gereklidir
2. MySQL veritabanı
3. Composer bağımlılıkları: `composer install`
4. Veritabanı yapılandırması: `config/database.php`
5. SMTP ayarları: `config/mail.php`

## Kullanım

- Anasayfa: Firma kayıt ve giriş
- Admin Panel: Sistem yönetimi
- İdari İşler: Talep yönetimi
- Çalışan: Talep oluşturma ve takip
